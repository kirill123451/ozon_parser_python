# Парсер поисковой выдачи Ozon

Программа на Python для мониторинга позиций товаров в поисковой выдаче Ozon (первые 100 результатов).

## Запуск на Windows

1. Откройте командную строку (cmd) в папке проекта.
2. Установите библиотеку автоматизации:
```bash
pip install playwright
```
3. Скачайте зависимости браузера Chromium:
```bash
playwright install chromium
```
4. Запустите парсер для проверки одного товара:
```bash
python parser.py "дождевик" "4367148108"
```
5. Запустите автоматический тест устойчивости (3 раза по 30 секунд):
```bash
python run_3_times.py
```

## Тестовые данные
В соответствии с ТЗ выбраны 3 товара из разных категорий:
1. `дождевик` (SKU: `4367148108`) — категория одежды и аксессуаров.
2. `симфония духи женские` (SKU: `3540184175`) — категория парфюмерии с высокой плотностью карточек.
3. `масло розмарина активатор роста волос` (SKU: `2433210524`) — категория косметики и ухода.
