# Лог подхода (Approach Log)

## Итерации разработки
1. **HTTP-запросы напрямую:** Попытка отправлять классические GET-запросы через `requests` к поиску Ozon мгновенно приводит к блокировке (ошибка 403 / защита Cloudflare).
2. **Использование Playwright (Chromium):** Переход на эмуляцию полноценного браузера. Это позволяет скрипту выглядеть как обычный пользователь на Windows, благодаря чему Ozon отдает поисковую выдачу без капчи.

## Использование ИИ (AI)
- AI помог составить регулярное выражение и логику строковых методов для извлечения уникального ID товара (SKU) из сложных динамических URL-адресов Ozon.

## Ручные правки
- Добавлена принудительная задержка в 3 секунды после открытия страницы (`wait_for_timeout`). Без неё скрипт пытался читать данные до того, как скрипты Ozon успевали полностью отрисовать список товаров.
